# 外国人のお客さまへのゆびさしカード

「現金のみです」「靴を脱いでお上がりください」など、お店で使う決まった言い回しを選んでおくと、日本語・英語・中国語（簡体字）・韓国語を並べて大きく見せたり、A4のカードにして印刷したりできるWebページです。
100日100プロダクトチャレンジ Day098。

## できること

- **選ぶ**: 14の決まった言い回し（お金／席と予約／撮影／店内のルール／ご案内）から、お店で使う文にチェックを付ける
- **見せる**: 選んだ文をタップすると、その1文が4言語で画面いっぱいに出る。文字は画面に入りきる最大の大きさに合わせる（横向きでは2×2）。「前」「次」で切り替え
- **印刷カード**: 選んだ文を全部、A4縦の1枚に並べる。店名（任意）を上に入れられる。文の数に合わせて文字の大きさを変え、1枚に収める

## 作らないもの

自由な文章の翻訳・翻訳API・音声の読み上げ・カメラでの翻訳・会話モード。
英語・中国語・韓国語は、決まった14の言い回しに付けた対訳だけです。

## 保存について

- 選んだ文と店名は、この端末のブラウザ（localStorage）にだけ保存します。外には送りません
- 「選んだ文と店名を消す」で消えます
- 登録・ログインはありません

## 作り

HTML1枚（`index.html`）。外部ライブラリなし。アクセス解析に Cloudflare Web Analytics を使っています（フッタに明記）。
